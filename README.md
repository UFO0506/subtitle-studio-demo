# 影片字幕工作室展示版

看 AI 怎麼聽、看、想，把語音辨識的初稿改成正確的字幕。

- **修正的字幕：** 比較 Whisper 初稿和 AI 修正結果，每句都有理由。
- **AI 看到的畫面：** AI 看完每段畫面後寫下的紀錄。
- **AI 的思考過程：** 聽、看、想、改四個階段，以及全片理解和名詞表。
- **AI 此刻的判斷：** 影片播到哪，就顯示 AI 對當下這句的判斷。

字幕都是字幕服務實際跑出的結果。「用我的影片」可以處理 10 分鐘以內的 MP4 或 MOV，作者的主機要開著；服務沒開時仍可看範例。

本機預覽：

```bash
python -m http.server 8124
```

擴充規則見 [CLAUDE.md](CLAUDE.md)。
